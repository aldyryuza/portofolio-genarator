# Roadmap — execute sequentially

M0: audit Laravel starter, git, `.env.example`, test setup, UI concept, architecture approval.
M1: auth owner-only, routes, navigation, profile settings, basic dashboard, access/security tests.
M2: taxonomy, skills, project CRUD, publishing/drafts, featured/order, slug SEO, relational tests.
M3: media library, secure uploads, project gallery, remote video embeds, private/public file access.
M4: public landing, about, projects filtering/detail, experience, education, certificates, CV; responsive design and SEO.
M5: CV upload/version download, contact form with anti-spam and admin inbox.
M6: PDF portfolio export (selective content, themes/templates), then PPTX export (as a separate feature), download permissions, document validation.
M7: polish, accessibility, Lighthouse, performance, backup, CI, deployment checklist and release notes.

Never implement all milestones in one huge unreviewed commit.
